# Artispreneur plugins for Claude

Generated by `npm run claude-plugins:build` from the canonical Artispreneur skill and desk catalog. Do not edit by hand.

Marketplace name: `artispreneur`. Every plugin is read-only and draft-first, published by Artispreneur Inc. under license `UNLICENSED`, and declares the public MCP server `https://www.artispreneur.com/mcp` (no sign-in).

```
/plugin marketplace add diamitani/artispreneur-claude-plugins
/plugin install artispreneur@artispreneur
```

Install any single skill or desk the same way, for example `/plugin install artispreneur-create-llc@artispreneur`.
